TABLINUM - Prima Via (offline Latin reader) - Windows 11

START
  Double-click  Tablinum.html
  The reader opens in your default browser (Edge, Chrome or Firefox).
  No console window, no installation, no Internet connection.

  "Start Tablinum.cmd" still works too (it may flash a console for an instant).
  For the picture exercises, open "Picture Practice.html" or use
  "Start Picture Practice.cmd".

KEEP YOUR PROGRESS
  Progress is saved in the browser for this folder. Before moving or replacing
  the folder, open Progressus > Export backup JSON, then restore it in the new
  copy. Extract new versions to a new folder; do not mix old and new files.

AUDIO
  All 67 Lectio sentences are mapped to owner-supplied Arjun MP3s under
  audio/narration/arjun. Chapter I is owner-approved; Chapters II–VIII are
  new recordings awaiting your listening review. Seven vocabulary words use
  Arjun; laeta uses a clearly labelled Miriam fallback.
  Roman reading music: three original, low-volume MP3 tracks, overlapping
  through 8-second crossfades. Music automatically ducks during speech.
  One sentence plays when clicked, and stops when it finishes.

FIRST START
  The course guide explains Lectio, Exercitia, Memoria and progression.
  Select Enter the Tablinum to begin. Reopen it with Course guide.
  You can choose not to show the guide automatically next time.

FONT
  The reader uses Palatino Linotype, which Windows already has. A bundled
  open-licence face (Gentium Book Plus, assets\fonts) is used only as a
  fallback. Nothing is installed system-wide.
