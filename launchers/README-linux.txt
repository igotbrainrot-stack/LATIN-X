TABLINUM - Prima Via (offline Latin reader) - Linux Mint

START
  Double-click  Tablinum.html  in the file manager.
  The reader opens in your default browser (Firefox or Chromium).
  No terminal, no installation, no Internet connection.

MENU ENTRY AND DESKTOP ICON (optional, once)
  Double-click  linux/install-launcher.sh  and choose "Run".
  Tablinum then appears under Education in the menu and on the desktop.
  If you move this folder, run it again. linux/uninstall-launcher.sh removes it.
  (If the file manager opens the script as text instead: right-click it,
  Properties > Permissions > "Allow executing file as program".)

KEEP YOUR PROGRESS
  Progress is saved in the browser for this folder. Before moving or replacing
  the folder, open Progressus > Export backup JSON, then restore it in the new
  copy. Extract new versions to a new folder.

AUDIO
  All approved Miriam recordings are in audio/narration/miriam, including
  sentences 7 and 9 and the words quoque, vīlla and aqua.
  Five of them (sentence 7 V6b and V6a, sentence 9 V5a, quoque V4, aqua V3) are
  new recordings with the same voice and settings, made because the originals
  could not be downloaded; vīlla V2 is the original.

FONT
  Linux Mint has no Palatino, so the reader uses the bundled open-licence face
  Gentium Book Plus (assets/fonts). Nothing is installed system-wide.
