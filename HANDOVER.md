# HANDOVER — Tablinum (LATIN X)

For the next developer or AI agent. Read this first, then [docs/REFINEMENT_REPORT_20261108.md](docs/REFINEMENT_REPORT_20261108.md) for what the latest pass changed and [docs/FEATURE_INVENTORY.md](docs/FEATURE_INVENTORY.md) for the regression checklist.

## 1. What it is

A static, offline Latin reader. Plain HTML + classic `<script>` files, opened directly from disk (`file://`). No build step to run it, no server, no network, no ES modules or `fetch` (both break on `file://`). Owner decisions and approval states are data in the repo and must be respected (section 6).

## 2. Architecture


The additive `app/welcome/welcome.js` + `.css` is the first-run guide; it supports Escape, keyboard focus cycling and the local-storage skip option. The paper page uses the existing single CSS `body::before` layer only.

Owner-private MP3s are deliberately gitignored. `docs/audio/ARJUN_OFFLINE_MEDIA_CHECKSUMS_20261110.json` specifies exactly 78 local inputs required before build; the build fails on any mismatch. Do not commit binaries, signed Runway URLs or private review files. `content/narration.js` is a normal integrated catalogue, **not** an overlay appended by a Python launcher. Chapter I Arjun is owner-approved; 58 Chapter II–VIII takes await owner listening approval. The word *laeta* is a separately labelled Miriam fallback. No first-launch network or patching is part of this branch.

Script order in `index.html` matters (globals). `tests/phase3a-relocation.test.cjs` enumerates the exact tags; add new ones there.

## 3. Launching

- **Source tree:** open `index.html` (or `Start Tablinum.cmd` on Windows).
- **Release, Windows 11:** double-click `Tablinum.html` — redirects to `index.html` in the default browser; no console.
- **Release, Linux Mint:** double-click `Tablinum.html`; optionally run `linux/install-launcher.sh` once (writes `~/.local/share/applications/tablinum.desktop` and a trusted desktop icon, `Terminal=false`, Exec quoted for spaces/`$`/`%`). Re-run after moving the folder.
- Learner progress lives in browser storage keyed to the folder path. Moving folders = export/restore backup.

## 4. Building and testing (Windows or Linux, Node 22+)

```
npm install                      # dev deps only: axe-core 4.10.3, ts-fsrs 5.4.2 (exact)
npm test                         # 34 Node suites, ~10 s
npm run test:browser-all         # 16 real-Chromium file:// suites (needs Playwright + Chromium)
npm run test:narration           # approved-audio integrity
npm run build:release            # dist/: windows.zip, linux.tar.gz, source.zip, SHA256SUMS.txt
npm run checksums                # regenerate root SHA256SUMS.txt after any change
```
`build-release.cjs` has no dependencies (own ZIP and tar.gz writers). The learner file set is the `RUNTIME` constant at its top; `tests/release-package.test.cjs` fails if a page requests a file that is not packaged, or if development/historical files leak in.

## 5. Important assets

- `assets/art/b01/*.webp` — nine owner-approved scenes (+ thumbs). SHA/size/polygon gates in `tests/art-replacement-regions.test.cjs`. Never replace without owner sign-off.
- `audio/narration/arjun/*.mp3` — 75 current local narrator files (74 Arjun including 67 sentence clips, plus labelled Miriam `laeta` word fallback), Git-ignored. `docs/audio/ARJUN_OFFLINE_MEDIA_CHECKSUMS_20261110.json` pins every included MP3; historical Miriam variants and approvals are preserved separately but do not automatically ship.
- `assets/fonts/gentium-book-plus/` — OFL fallback face; `assets/icons/` — app icon.
- `vendor/ts-fsrs.umd.js` — pinned, verified by `npm run test:vendor-fsrs`.

## 6. Constraints you must keep

- `app/legacy-runtime.js` lesson data, questions, answers and cloze are locked (`legacy-content-lock`, `phase3a-relocation`). `index.html` may change only in the enumerated `<script>`/`<link>` tags. Put visual changes in `app/styles/tablinum-polish.css`.
- Pilot chapters, 44 picture questions and all lexemes are **unsigned**. Never mark anything approved; only the owner signs.
- Storage: never overwrite `tablinum-source-review-v02` (v4); v5 is `tablinum-state-v5`.
- Narration: show canonical Latin only (`Līvia`, `quoque`); TTS aliases (`Lii-wia`, `Lee-wee-ah`, `Kwoh-kweh`) must never be learner-visible. Owner approval tier is `owner_not_latinist`. Sentence 7 default = V6b. Don't fabricate word timings.
- Don't merge to `main`, publish releases or change historical art reviews. GitHub PR #2 merged on 10 Nov 2026; the audit branch has separate pending work. Do not merge or publish without owner approval.
