# LATIN X — Attribution and data-provenance notes

Tablinum's present eight short Latin chapters and existing visual application are retained from the original LATIN X project. The Phase 1 lexical review system has **zero reviewed lexemes**. Its committed review sheet includes **50 exact-headword and frequency-rank metadata hints** obtained from the owner-provided Dickinson Latin Core list; those hints are unapproved reference suggestions, not a finished dictionary. It copies only existing in-app glossary candidates into an unapproved editorial queue.

**DCC-derived review-sheet metadata (attribution):** Dickinson College Commentaries, Latin Core Vocabulary, Christopher Francese and contributors, Dickinson College. https://dco.dickinson.edu/vocabulary — CC BY-SA 3.0 Unported according to that page's terms. Main project's terms: https://dcc.dickinson.edu/terms-use. The existing `curriculum/lexicon/review-sheets/legacy-candidates.csv` includes DCC-derived headword/rank hints and is distributed with this attribution under **CC BY-SA 3.0 Unported** as stated by DCO; downstream adaptations should preserve applicable share-alike terms. The complete uploaded DCC CSV is **not** in the Git repository.

The natural-method approach and Latin-first pedagogy are informed by published descriptions of Hans Ørberg's *Lingua Latina per se illustrata*; **no protected Ørberg text, artwork, audio or workbook material is included** in the approved lexical registry.
