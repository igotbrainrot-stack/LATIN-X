## 3. Make the grammar gate fail closed (most important code fix)

`scripts/lib/grammar.cjs` only checks the 12 features in `grammar-features.json`. Any morphology that matches **no** feature passes silently. For example, a chapter 3 lesson could use a future passive, an imperfect, a plural nominative or an infinitive and still compile.
- **Fix:** every token with an `lx` must match at least one feature that is introduced at or before its chapter. Otherwise report `unmapped morphology <morph> for <token>`. Manual previews count as allowed exceptions.
- **Expand `grammar-features.json`** from the `grammar_focus` of all 130 chapters (about 120–160 features). This must include:
  - all cases × numbers;
  - the tenses of each mood and voice;
  - infinitives, participles, gerund and gerundive, supine;
  - comparison and adverbs;
  - pronoun lexeme features (is, hic and ille, suus and sē);
  - plural imperatives;
  - the v3 pronoun chapters (11, 14, 15, 16, 20, 26).
- Note that chapter 1 already needs `n.nom.pl` and `sunt`, because the plan says "est/sunt".
- **Add a test:** a fixture chapter 3 lesson containing an imperfect verb must FAIL.
